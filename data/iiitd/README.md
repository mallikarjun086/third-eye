# IIIT-D Forensic Sketch Dataset Acquisition Instructions

## Acquisition Steps:
1. Apply for access at IIIT-Delhi Image Processing and Computer Vision Lab (IPAG).
2. Complete signed academic agreement.
3. Download `IIITD_Forensic_Sketch_Database.zip`.
4. Extract into `data/iiitd/`.
5. Expected structure: `viewed/`, `semi_forensic/`, `forensic/` subfolders.
6. Run `python data/iiitd/validate.py` to verify physical images.
